# Niet aangekomen ongedaan

## Wanneer
Persoon was als no-show gemarkeerd, maar dit was onterecht.

## Voorwaarden
- Status is **Niet aangekomen**

## Flow

1. Receptionist klikt "Niet aangekomen ongedaan" via actiemenu
2. Status wordt direct teruggezet (geen modal/bevestiging)

## Resultaat
- Status wijzigt naar **Verwacht**
- Persoon is weer beschikbaar voor aanmelden
